### Backwards-incompatible changes

- Drop support for Python 2.x. The Python bindings now require Python 3.1 or later.
- Drop support for Perl 5.10. The Perl libraries and the remctl test suite now require Perl 5.12 or later.

### Bug fixes

- Fix building from Git with Automake 1.17 and later.
- Attempt to fix linking on systems with a stray `lib64` directory.
- Fix build issues when `pkg-config` is not installed.

### Other changes

- The remctl change log is now formatted in Markdown, named `CHANGELOG.md`, and maintained using [scriv](https://scriv.readthedocs.io/en/latest/).
- remctl now uses [semantic versions](https://semver.org/).
